# Life OS v2.2 — Release Android nativa

Esta pasta preserva o código e os recursos que compõem a versão 2.2.

## Destaques
- UI compacta inspirada na referência fitness enviada, mantendo a paleta `#002A32` e `#ED254E`.
- Ícone adaptativo em formato de compasso, sem aro branco ou símbolo genérico de check.
- Tipografia ampliada, ícones vetoriais Material e transições discretas.
- Tarefas personalizadas com XP, repetição diária, dias úteis, fins de semana, dias selecionados ou tarefa única.
- Lembretes sonoros Android com AlarmManager, notificações e restauração após reinicialização.
- Temporizador com tempo restante preservado ao pausar e sair do aplicativo.

O projeto compilável completo está na raiz do repositório. O código Kotlin e o agendador de alarmes estão preservados no arquivo de origem reconstruído pelo workflow a partir de `payload-b64/`.
