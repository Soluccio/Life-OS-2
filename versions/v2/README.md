# Life OS — Projeto Android v2

Projeto Android nativo completo da segunda geração do Life OS. A release atual é **2.1**.

## Estrutura
- `app/src/main/java/com/sol/lifeos/MainActivity.kt.gz`: código Kotlin da interface e das funcionalidades.
- `app/app-build.gradle.kts`: configuração do módulo Android.
- `app/AndroidManifest.xml`, `app/styles.xml`, `app/ic_launcher.xml`: recursos do aplicativo.
- `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`, `gradle/wrapper/`: configuração do build.

O projeto de build ativo fica na raiz do repositório. A pasta `versions/v2` preserva o projeto completo da linha v2.
