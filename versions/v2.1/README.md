# Life OS v2.1

Snapshot da atualização visual e funcional 2.1 da linha Android v2.

- Paleta de marca: `#002A32` e `#ED254E`.
- Layout híbrido e compacto com ícones vetoriais Material.
- Compatibilidade de barras de status e navegação.
- XP consistente, protocolo de sobrevivência que recolhe a rotina normal e temporizador com pausa persistente.
- Mantém missões, calendário, histórico, conquistas, skills e recompensas.

O projeto de build ativo está na raiz do repositório; o projeto integral da linha v2 está em `versions/v2/`.
