# Life OS v2.2.1

Hotfix de interface e estado:
- A tela principal agora observa a revisão dos dados e recompõe o conteúdo após concluir/desmarcar uma missão, preservando a posição e o estado local da aba.
- Cores mais escuras: fundo quase preto com verde-petróleo; coral usado com moderação.
- Dashboard, indicadores e linhas de missão mais compactos e minimalistas.
- Mantidas as funcionalidades da v2.2, incluindo tarefas personalizadas, repetição, alarmes, XP, conquistas, skills, loja e timer.

A fonte Kotlin é reconstruída e corrigida pelo workflow a partir do bundle versionado da v2.2.
