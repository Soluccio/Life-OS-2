# Life OS 2 — Android nativo

Aplicativo Android nativo em Kotlin + Jetpack Compose. Não utiliza WebView nem depende de conexão à internet.

## Gerar APK
O GitHub Actions compila automaticamente o APK de debug a cada push na branch `main`. Abra **Actions → Build Life OS APK → última execução → Artifacts** e baixe `life-os-debug-apk`.

Também é possível iniciar manualmente em **Actions → Build Life OS APK → Run workflow**.

## Recursos
- Painel de jogador, XP e níveis.
- Ritual de chegada e modos de sobrevivência.
- Missões semanais, calendário e histórico.
- Conquistas e recompensas personalizadas.
- Temporizador para estudo, casa e descanso.
- Skills de lavanderia e calistenia.
- Meta progressiva de sono.

## Privacidade
O progresso é salvo no armazenamento privado do aplicativo no próprio aparelho. Não há envio dos dados para servidores.
